# v0.3.2 - Look Target 머리/눈 각도 제한 Inspector 노출

**릴리스 날짜**: 2026-06-26

Look Target의 머리/눈 추종 각도 제한을 Inspector에서 직접 조정할 수 있도록 노출했습니다. 기존에는 Rig 셋업 시 코드에 하드코딩되어 있어 조정하려면 생성된 `MultiAimConstraint` 컴포넌트를 직접 열어야 했습니다.

## 주요 변경사항

### 1. 머리 각도 제한 필드 노출 (headAngleLimit)

- 기존에 Rig 셋업 시 `-45°~45°`로 하드코딩되어 Inspector에서 조정할 수 없었던 머리 추종 각도를 `headAngleLimit` 필드로 노출
- `[Range(0, 90)]`, 기본값 45°
- Inspector "Head Control Settings" 섹션에 슬라이더로 표시
- 머리 `MultiAimConstraint`의 limits에 적용

### 2. 눈 각도 제한 필드 노출 (eyeTransformAngleLimit)

- Transform/TransformCorrected 전략에서 `-20°~20°`로 하드코딩됐던 눈 회전 범위를 `eyeTransformAngleLimit` 필드로 노출
- `[Range(0, 90)]`, 기본값 20°
- Inspector "Eye Control Settings"의 Transform 전략 분기에 슬라이더로 표시
- 눈 `MultiAimConstraint`의 limits에 적용
- 기존 BlendShape 전략 전용 `eyeAngleLimit`(추종 cutoff, 기본값 10°)과는 **별개 필드**로 분리 — 의미(cutoff vs clamp)와 기본값이 다르기 때문

### 3. Edit / Play 모드 즉시 반영

- `MultiAimConstraint`의 limits 필드는 `[SyncSceneToStream]` 속성을 가지므로, 값 변경 시 Rig 재빌드(`RigBuilder.Build()`) 없이 다음 프레임에 자동 반영됨
- **Edit 모드**: 슬라이더 변경 시 이미 생성된 constraint에 즉시 적용 (`ApplyAngleLimitsInEditor`)
- **Play 모드**: `UpdateLookTarget`에서 매 프레임 동기화 (`ApplyAngleLimitsToConstraints`)
- Rig 셋업 메서드도 하드코딩 대신 필드값을 사용하며, 기존 constraint도 셋업 시 최신 필드값으로 갱신

## 호환성

- **하위 호환**: 기존 동작과 동일한 기본값(머리 45°, 눈 20°) 사용 — 기존 씬/프리팹은 새 필드가 기본값으로 초기화되어 동작 변화 없음
- BlendShape 전략의 기존 `eyeAngleLimit`/`eyeAngleLimitThreshold` 동작은 그대로 유지
