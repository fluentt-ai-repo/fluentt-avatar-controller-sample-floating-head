# v0.5.0 - Animation Rigging 의존성 제거 (룩타겟 직접구동 전환)

**릴리스 날짜**: 2026-07-13

`com.unity.animation.rigging`(`MultiAimConstraint` / `RigBuilder` / `Rig`) 의존성을 패키지에서 완전히 제거했습니다. AvatarControllerSample v0.5.0과 동일한 변경으로, 룩타겟(머리·눈 조준) 기능은 v0.4.0의 **레스트 캘리브레이션 직접구동 솔버**만으로 그대로 동작합니다.

## 배경

v0.4.0(ACS 솔버 포팅)에서 이미 머리·눈이 직접구동 솔버로 동작하고 있었고, `MultiAimConstraint`는 `weight = 0`으로 침묵당한 채 리그에 남아만 있었습니다. v0.5.0은 이 죽은 컨스트레인트 경로와 그 셋업 코드, 그리고 `com.unity.animation.rigging` 의존을 전부 제거합니다.

## 변경 사항

### 제거
- **`com.unity.animation.rigging` 참조**: asmdef(Runtime/Editor)의 `Unity.Animation.Rigging` references 와 `FLUENTT_ANIMATION_RIGGING_AVAILABLE` versionDefines 삭제.
- **`EEyeAimMode` / `EHeadAimMode` enum** 및 대응 `eyeAimMode` / `headAimMode` 필드 삭제.
- **컨스트레인트 셋업 코드**: `SetupLookTargetRigAtRuntime` / `DestroyLookTargetRigAtRuntime` / `RebuildRig` / `UpdateConstraintSources` / `ApplyAngleLimitsToConstraints` / `AutoConfigureLookAimAxes` / `ConfigureAimAxisForBone` / `SetupSingleEyeTrackingAtRuntime` 및 `LookTargetController.Set*AimConstraint` / `SnapHeadVirtualTargetToTarget` 삭제.
- **Editor**: `LookTargetRigSetup.cs`, `LookTargetToggle.cs` 삭제. 인스펙터의 컨스트레인트 절·Aim Mode 드롭다운·런타임 Rig 버튼·twist 진단 제거.

### 유지 (동작 무변경)
- 직접구동 헤드/눈 솔버, 세 눈 전략(`BlendWeightFluentt` / `Transform` / `TransformCorrected`).
- `EnsureVirtualTargetRefs`: BlendWeightFluentt가 조준하는 `EyeVirtualTarget`을 런타임 자동 생성(시간 스무딩 + 0.5m 근접 클램프).
- 공개 API `FindLookTargetTransforms` / `SetLookTarget` / `SetLookTargetEnabled`.

## Breaking Changes

- 공개 API `SetupLookTargetRigAtRuntime()` / `DestroyLookTargetRigAtRuntime()` / `RebuildRig()` / `LookTargetController.Set*AimConstraint()` / `SnapHeadVirtualTargetToTarget()` 제거.
- `EEyeAimMode` / `EHeadAimMode` 타입 제거.
- **마이그레이션**: 아바타 프리팹에서 rig 스캐폴딩을 제거해야 한다(메인 저장소 strip 툴 참고).

## 검증

- 디파인을 강제로 끈 상태에서 패키지 내부 컴파일 에러 0.
- `AvatarCompatibilityTest`에서 FloatingHead 아바타(`260105_taerin_rig`, BlendWeightFluentt) 포함 rig 제거 상태로 Play — `EyeVirtualTarget` 자동 생성 확인, 룩타겟 정상 동작. constraint 코드 삭제 전후 동작 동일.
