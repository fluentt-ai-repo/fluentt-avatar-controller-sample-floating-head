# v0.6.3 - 미사용 UnlimitedFrameRate 제거 (런타임 IMGUI 의존성 해소)

**릴리스 날짜**: 2026-07-30
**이전 버전**: [v0.6.2](v0.6.2.md)

데드코드 1건을 제거합니다. 동작 변경은 없습니다 — 이 컴포넌트는 어느 씬에도 붙어 있지 않았습니다.

## 1. 무엇을 지웠나

`Runtime/UnlimitedFrameRate.cs`. 프레임 상한을 해제하고 좌상단에 FPS 오버레이를 그리는 개발용
유틸입니다. 제품 기능이 아닙니다.

```csharp
Awake()  → Application.targetFrameRate = -1;  QualitySettings.vSyncCount = 0;
OnGUI()  → "16.7 ms (60 fps)" 오버레이
```

## 2. 왜 지웠나 — 빌드 크기

`com.unity.modules.imgui` 는 **manifest 에서 제거할 수 없는 모듈**입니다. 모든 에디터 스크립트가
`GUIContent` / `GUIStyle` 을 쓰기 때문입니다. 하지만 에디터 코드는 플레이어 빌드에 들어가지 않으므로,
**런타임 어셈블리가 IMGUI 를 참조하지 않으면 IL2CPP 엔진 코드 스트리핑이 wasm 에서 모듈을
걷어냅니다.**

이 파일이 **이 패키지의 유일한 런타임 IMGUI 사용처**였습니다. 남겨두면 `UnityEngine.IMGUIModule` 이
계속 링크됩니다.

## 3. 안전성 확인

삭제 전에 GUID(`e267c3d3dbcb72941a71f53ecccf20a7`)로 로컬 Unity 프로젝트 7곳(MarketonProjectDemo,
eyeline-interface, meta-x-grace-plastic, plastic-surgery-superproject, talkmotion-daegu-client,
mirabel-unity-webgl, FluenttModuleLibrary)의 씬·프리팹·에셋을 전수 검색했습니다. **참조 0건**이며,
코드에서 타입을 참조하는 곳도 없습니다. missing script 가 발생할 대상이 없습니다.

WebGL 동작 변화도 없습니다 — WebGL 은 `vSyncCount` 를 무시하고 `targetFrameRate = -1` 이 기본값이라
`Awake()` 가 하던 일은 기본 상태와 동일합니다.

## 4. 검증

제거 후 이 패키지의 런타임 어셈블리에 IMGUI 타입 사용 **0건**입니다. Editor 어셈블리는 영향받지
않습니다.
