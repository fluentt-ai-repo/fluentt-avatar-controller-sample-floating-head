# v0.7.0 - Unity 6.4 Obsolete API 마이그레이션 (ACS v0.7.0 미러링)

**릴리스 날짜**: 2026-08-03
**이전 버전**: [v0.6.3](v0.6.3.md)

> Unity 6.4가 deprecated로 표시한 `GetInstanceID()` 사용처를 `GetEntityId()` 로 교체했습니다.
> 그 결과 **최소 Unity 버전이 2022.3 → 6000.4로 올라갑니다.** 🚨 BREAKING
> AvatarControllerSample v0.7.0과 동일한 변경입니다.

---

## 1. 배경

Unity는 인스턴스 식별자를 `int` 기반 InstanceID에서 `EntityId` 구조체로 교체하고 있습니다.
6.4는 경고, 6.5부터는 컴파일 에러입니다. Talkmotion SDK v0.22.0과 보조를 맞춰 정리했습니다.

## 2. 변경 내용

### 2.1 탭 상태 키 (`FluentTAvatarControllerFloatingHeadEditor.cs`)

```diff
- $"FluentTAvatarControllerFloatingHead_SelectedTab_{target.GetInstanceID()}"
+ $"FluentTAvatarControllerFloatingHead_SelectedTab_{target.GetEntityId()}"
```

`SessionState` 키 문자열이 달라지므로, 업그레이드 직후 **한 번은 선택 탭이 첫 탭으로 초기화**됩니다.

### 2.2 클립 변경 감지 (`FluentTAvatarControllerFloatingHeadEditor.OneShotMotion.cs`)

```diff
- private readonly Dictionary<string, int> previousClipInstanceIds = new();
+ private readonly Dictionary<string, EntityId> previousClipEntityIds = new();

- int currentId = clip != null ? clip.GetInstanceID() : 0;
+ EntityId currentId = clip != null ? clip.GetEntityId() : EntityId.None;

- if (prevId != currentId && clip != null)
+ if (!prevId.Equals(currentId) && clip != null)
```

`EntityId` 에는 `!=` 연산자가 없어 `Equals(EntityId)` 를 씁니다. `Equals(int)` 오버로드는 그 자체가
obsolete이므로 쓰면 안 됩니다. 빈 값은 `0` 대신 `EntityId.None` 입니다.

`overrideEyeControl` / `overrideEyeBlink` 자동 감지 동작은 변하지 않습니다.

## 3. 최소 Unity 버전 상향 🚨 BREAKING

```diff
- "unity": "2022.3",
+ "unity": "6000.4",
```

2022.3 프로젝트에서는 v0.6.3을 고정해서 쓰세요.

## 4. 변경된 파일

| 파일 | 변경 |
|---|---|
| `Editor/FluentTAvatarControllerFloatingHeadEditor.cs` | `GetEntityId()` |
| `Editor/FluentTAvatarControllerFloatingHeadEditor.OneShotMotion.cs` | 클립 ID 캐시를 `EntityId` 로 전환 |
| `package.json` | `unity` 2022.3 → 6000.4, 버전 0.7.0 |
